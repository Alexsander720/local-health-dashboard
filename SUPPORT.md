# Support

## Questions And Bugs

Use GitHub Issues for reproducible bugs, feature requests, and questions about
the synthetic demo or supported export formats.

Before opening an issue:

1. Reproduce the problem with demo mode when possible.
2. Remove names, health records, device IDs, IP addresses, tokens, cookies,
   database files, and local filesystem paths.
3. Include the operating system, Python version, command, and relevant error.

## Medical Questions

This project is wellness software, not a diagnostic service. Do not use its
output as a substitute for professional medical advice or emergency care.

## Security

Follow [SECURITY.md](SECURITY.md) for vulnerabilities or accidental exposure
